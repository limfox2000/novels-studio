  - **保存语义**：活跃章节仅在手动保存成功后持久化，刷新后仍高亮同一章；生成前与保存前都会先同步当前章场景。

- **2026-10-24 自动保存改为手动保存**
  - 用户反馈自动保存过于频繁。新增 `src/stores/manualPersistStorage.ts` 替代 `debouncedPersistStorage.ts`：编辑只更新内存中的最新 payload，不写 localStorage；点顶栏「保存」或 Ctrl/Cmd+S 才写入当前作品（`nc2-sim-v1`）并同步同名命名存档。
  - 保存状态扩展为 `idle / unsaved / saved / error`；工具栏提示「有未保存改动」，有未保存改动时刷新/关闭页面弹出浏览器离开确认。无待保存数据时按保存也会写入最新内存状态（含视口/当前画布）。
  - 选中节点、React Flow 测量、平移/缩放视口、切换画布标签不计入未保存内容（瞬时字段）；保存失败保留错误提示直到下次保存成功；超配额有明确提示。
  - 载入命名存档会立即持久化为当前作品；新建作品会立即写入空白状态；书架打开/新建/导出前会提示未保存改动，避免误丢。大纲/正文流式生成不再自动落盘，生成结果需手动保存。
  - 验证：`pnpm build` 通过并部署；新增部署 E2E（`e2e_manual_save`）覆盖零自动写入、瞬态操作不弄脏、按钮/Ctrl+S 落盘、命名存档同步、离开确认与刷新回到上次保存版本。全量回归通过，旧用例改为读取前显式保存。
