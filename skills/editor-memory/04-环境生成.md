# 环境生成 · 技能记忆

## 生成结构（固定契约，记忆条目只补充写法）
_生成/修订环境设定一律按此执行；结构本身不因调教改动。_
- 环境设定依次产出：名字 → 类型 → 描述；名字 16 字以内、贴合世界观的语言感，类型七选一（房间/建筑/社区/城镇/区域/床/物品——床=休息容器，物品=非容器的物件标记）
- 描述一段话、按 外观 → 功能 → 氛围 落笔；环境供正文生成取用作场景，细节要给得到、用得上
- 成组区域（村落/庄园/街区等）用区域规划一次产出：容器描述 + 逐座建筑的尺寸与排布，几何约束照协议执行

## 外观
_外观描写的写法——空间形态与标志细节的取舍偏好沉淀在这里。_
- 先给整体格局（范围、布局、材质质感），再落到一两个让人记住的标志细节；与题材世界观、人物身份自洽

## 功能
_环境功能的写法；环境如何承载人物活动与情节的偏好沉淀在这里。_
- 写清这处环境供什么活动使用、会酿成什么冲突或便利——让环境能参与叙事，而不只是布景

## 氛围
_氛围与感官的落法；光线、声音、气味等感官口味的偏好沉淀在这里。_
- 用一两笔感官细节定基调（光线、声音、气味），情绪指向与环境的用途一致
