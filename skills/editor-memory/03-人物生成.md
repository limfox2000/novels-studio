# 人物生成 · 技能记忆

## 生成结构（固定契约，记忆条目只补充写法）
_生成/修订人物设定一律按此执行；结构本身不因调教改动。_
- 人物设定依次产出：基础属性（人名/性别/年龄）→ 基础信息 → 身份信息 → 人物关系（按需）
- 人名/性别/年龄是节点字段：人名给贴合作品的语言感名字，性别 男/女，年龄给数字

## 基础属性（人名 · 年龄 · 性别）
_三项的取法；特殊题材有惯例口径时沉淀在这里（辅助需求，通常留空）。_
- 人名贴合题材世界观的语言感，年龄与身份、阅历匹配，性别按作品需要设定——三项都给全，字段直接可用

## 基础信息
_人物本身的样子与性情——核心沉淀区之一：不同题材的长相/身材/穿搭口径与性格立体化的偏好。_
- 长相、身材、习惯穿搭各一笔，落一个让人记住的外形标志（疤痕、饰品、惯常装束）；性格用具体行为倾向代替形容词堆叠：欲望、软肋、行事风格各占一点，与外形气质自洽

## 身份信息
_人物在世界中的位置与故事钩子——核心沉淀区之一：职业/身份设定与跟故事相关的特殊设计。_
- 职业与身份贴合题材和所处的环境层级（城镇/建筑/房间），写明其在故事中的位置、掌握的资源或秘密；与主线至少一处勾连

## 人物关系
_人物关系的搭法；特殊题材的关系网需求沉淀在这里（辅助需求，按需启用）。_
- 关系写成双向的（谁对谁怎样、谁欠谁什么），标明现状与张力；人物与主线、其他人物都要有落点
