# 卷生成 · 技能记忆

## 需求定位（固定契约，记忆条目只补充写法）
_卷介绍通常由创作者在卷管理界面维护，编辑代拟/修订时一律按此执行；结构本身不因调教改动。_
- 卷设定 = 卷名 + 卷介绍：卷名 20 字以内、带卷序与主题（如「第一卷 初入宗门」），介绍一段话、300 字以内
- 卷是多章节的大方向：只写整卷讲什么、推进到哪、达成什么；具体章节的任务与事件链留给章节需求与章节大纲
- 方向链从上到下：全文目标 → 卷介绍 → 章节需求 → 章节大纲；后续章节需求都从这段介绍里推敲

## 主线推进
_本卷在主线中推进到哪里的写法；分卷节奏与阶段目标的偏好沉淀在这里。_
- 点明本卷承接全书（或前卷）的哪一步、把主线推进到什么节点，给出本卷要达成的阶段目标——与全文方向的因果链一句话能接上

## 核心事件与人物
_本卷核心事件与主要人物的写法；卷级大事取舍的偏好沉淀在这里。_
- 概括本卷讲什么：一两个卷级大事件（谁、做什么、结果如何），点名本卷挑大梁的人物——这是卷内各章需求推敲的种子

## 期待感
_本卷期待感的写法；大爽点与跨卷悬念方向的偏好沉淀在这里。_
- 写明读者看这一卷图什么（本卷的大兑现）与卷末收在哪（跨卷悬念方向）；具体章节钩子由章节需求与大纲设计
