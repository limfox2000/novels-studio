# 全文目标 · 技能记忆

## 目标结构（固定契约，记忆条目只补充写法）
_拟全文目标一律按此执行；结构本身不因调教改动。_
- 全文目标依次写三部分：题材 → 主线 → 爽点预期，各占一小段、直接写内容，总长 500 字以内

## 题材
_题材定位的写法；不同题材的定调与口径偏好沉淀在这里。_
- 点明类型坐标：题材 + 子类型 + 气质对标（如「都市异能 + 悬疑 + 快节奏」），一两句定调，让全书生成共享同一基调

## 主线
_主线走向的写法；主线取舍与推进方式的偏好沉淀在这里。_
- 写清主角的根本目标、核心冲突与终局指向；主线是一条可陈述的因果链，从开局到结局一句话能说通

## 爽点预期
_爽点预期的写法；爽点类型与兑现节奏的偏好沉淀在这里。_
- 写明本书靠什么让读者持续爽：核心爽点类型与兑现频率预期（如「每卷一个大兑现、三章一个小兑现」）
