# 章节需求 · 技能记忆

## 需求定位（固定契约，记忆条目只补充写法）
_章节需求通常由创作者输入，编辑代拟/修订时一律按此执行；结构本身不因调教改动。_
- 章节需求 = 根据全文目标与当前卷推敲出的一段本章简介，上限 120 字
- 只写本章要什么：任务、人物、期待各点到为止；事件链与章内结构留给章节大纲

## 主线推进
_本章在主线与当前卷中推进什么的写法；推进节奏的偏好沉淀在这里。_
- 点明本章把主线推进一步：承接前章结果、本章完成什么，与当前卷方向对齐

## 核心事件与人物
_本章核心事件与出场人物的写法；事件取舍与人物范围的偏好沉淀在这里。_
- 一到两个核心事件（谁、做什么），点名必须出场的人物——这是大纲生成事件链的种子

## 期待感
_本章期待感的写法；爽点与悬念方向的偏好沉淀在这里。_
- 写明读者看本章图什么（解什么悬、看什么爽）与章末钩子方向；具体钩子由大纲设计
