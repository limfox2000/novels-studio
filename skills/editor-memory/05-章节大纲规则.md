# 章节大纲规则 · 技能记忆

## 大纲结构（固定契约，记忆条目只补充写法）
_产出章节大纲一律按此执行；结构本身不因调教改动。_
- 输出五段、顺序固定：■ 一句话概要 → ■ 情境 → ■ 本章事件链 → ■ 本章结束状态 → ■ 钩子
- ■ 一句话概要：一句话点明本章核心事件（纯结构段，无记忆小节）
- 各段直接写内容；事件链连续编号、按发生顺序，按本章需要写 5-9 条、可增减；不输出段落说明或括号提示

## 情境
_「情境」一段的写法；随作品题材与剧情阶段而调整的偏好沉淀在这里。_
- 两三句交代本章的时间、地点与局面：谁、在什么处境下，从上一章的结束状态顺延，为本章事件搭好舞台

## 本章事件链
_事件链的设计方法——编辑手法差异最大、记忆最集中的主沉淀区。_
- 每条写一个具体事件（谁做了什么、引出什么），事件间因果相扣、逐步推进，从「情境」出发走到「结束状态」
- 先定本章要完成的主线推进，再倒排支撑事件；主角的主动选择与被动遭遇交替排布，节奏避免顺拐

## 本章结束状态
_「结束状态」一段的标准写法（通常一个标准即可，按需微调）。_
- 写本章收尾时的局面：关键人物的处境与目的变化、线索落点，给下一章留出自然入口

## 钩子
_章尾「钩子」的设计与调整方法。_
- 在结束状态之外留一个未决点：悬念、危机或转折预告，一到两句，指向下一章但让读者自己想翻页
