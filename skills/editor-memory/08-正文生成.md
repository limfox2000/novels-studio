# 正文生成 · 技能记忆

## 执笔定位（固定契约，记忆条目只补充技法）
_执笔/修订正文一律按此执行；分工与输出方式本身不因调教改动。_
- 正文 = 按本章大纲把剧情展开成小说：写什么、按什么顺序写以大纲为准，不新增情节、不改事件走向
- 文风口径以全文规则为准（硬约束照办即可）；本技能的记忆只沉淀写作技法——同样的口径怎么执行得更到位
- 直接输出正文本身：不写章节名、标题、序号、解释或任何元话语，不用 Markdown 标记；开头从上一章的结尾自然顺延

## 开篇与入戏
_章首怎么起、多少字内入戏的技法。_
- 开场直接进局面：从人物的动作或当下情境切入，尽快入戏，不做长篇铺垫

## 描写技法
_描写落地的技法；镜头感与细节取舍的偏好沉淀在这里（密度与比喻口径以全文规则为准）。_
- 描写为叙事服务：挑最能推动情绪或剧情的两三个细节写透，其余带过；感官随人物的行动走，不静态堆砌

## 对话写法
_对话的写法；对话密度与口气区分的偏好沉淀在这里。_
- 每段对话有目的：推进剧情或人物关系；口气区分身份与关系，话里留潜台词，不把意思全部说破

## 节奏与张弛
_段间张弛的控法；详略与节奏偏好沉淀在这里。_
- 紧要处放慢写足、过渡处加快带过；张弛交替，避免同强度的段落连排

## 过渡与章尾收束
_场景与时间的过渡、章尾收束的技法。_
- 场景与时间切换不硬转：借人物动作或视线带过去；章尾按大纲的「结束状态」与「钩子」收，收在悬而未决的那一拍，不写总结性收场话
