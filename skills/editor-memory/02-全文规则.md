# 全文规则 · 技能记忆

## 规则结构（固定契约，记忆条目只补充写法）
_拟全文规则一律按此执行；结构本身不因调教改动。_
- 全文规则是正文生成的硬约束，依次写两部分：世界观规则 → 写作文风，总长 3000 字以内
- 每条一行、写成可检验的陈述，按条目组织，方便正文生成逐条遵循

## 世界观规则
_设定一致性约束的写法；世界观口径、能力边界与内容尺度的偏好沉淀在这里。_
- 写死不可违背的设定：力量/能力体系的边界与代价、社会形态与组织、称谓与专有名词口径——每条可检验，全书统一

## 写作文风
_文风约束的写法；叙述与语言的口径偏好沉淀在这里。_
- 写死叙事与语言口径：叙事人称与视角限制、句式节奏与语言风格基线、比喻与感官描写的密度倾向
